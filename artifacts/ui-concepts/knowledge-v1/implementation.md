## 本轮范围

- 笔记：云朵横幅、统一顶部搜索与账户入口、分类胶囊、笔记卡片；保留排序、网格/列表、置顶、批量操作和分页加载。
- 知识库：上传区、真实资料/片段计数、类型与名称筛选、文档表格、详情抽屉和网页剪藏；失败或中断的上传不再一直显示处理中。
- 知识图谱：可选择的标签节点、真实关联详情、打开笔记、缩放/平移/重置；手机保留可读字号和节点选择器。仍只在用户主动点击时查询语义关联。
- 统计：四个重点指标、七个辅助指标、紫色热力图、30 天折线趋势、分类环图；没有新增接口不支持的年份切换或伪造增长率。
- 知识广场：公开笔记卡片、独立作者/笔记链接、学习榜侧栏、完整榜单、分页去重和独立错误提示。

## 页宠约定（覆盖旧版 Skill 默认值）

用户明确要求首页也显示页宠，因此旧版 Skill 中“首页隐藏悬浮页宠”的规则不再适用。本轮没有改写已安装的 Skill 文件。

`MainLayout` 中只有一个持续挂载的 `Pet`，放在工作区滚动/裁剪容器外。首页及所有使用此布局的登录后页面均可显示；登录、注册、公开分享等不使用此布局的页面未擅自增加宠物。

保留角色、名称、好感度、事件奖励、拖动与显示开关。移动端不再强制隐藏，缩小为 88px；位置和气泡限制在屏幕内。拖动不会误判成点击奖励，支持 Enter/空格互动。知识页右上角云朵按钮可以切换显示；其它页继续使用已有命令面板或页宠设置。主动关闭的显示偏好不会被强制覆盖。

全局命令面板与文档抽屉层级高于悬浮页宠。
