## 三、推荐测试流程

1. **导入笔记**：新建 12 篇笔记（标题/分类/标签按上表），或直接复制文件内容粘贴
2. **检查列表**：网格/列表视图、分类筛选、标签筛选、排序、无限滚动
3. **检查首页**：最近记录（含无标签笔记不报错）、知识图谱预览、成长卡
4. **检查双链**：打开 01-RAG技术入门 → 反向链接面板应显示 03/05/09/10/11 的引用
5. **检查图谱**：图谱页应显示节点与双链实线；点「加载语义关联」应出现虚线相似边
6. **上传资料**：把 documents/ 下文件上传到知识库，查看切片数
7. **AI 问答**：问"什么是 RAG"（应引用笔记）、"数据库优化有哪些手段"（应引用资料）
8. **回顾**：把 01/02/03 标记回顾，测试 AI 出题与打卡
9. **搜索**：搜"向量"（中文）、"Hello World"（英文）、"Python"
10. **导出**：把 11-日记模板示例 导出 HTML / 打印 PDF 验证富格式

## 四、清理

测试完可在笔记列表批量勾选删除测试笔记；知识库删除对应文件。测试数据不会影响真实使用。
