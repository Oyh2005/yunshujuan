# Python 学习路线

## 第一阶段：基础语法（2 周）

- 变量、数据类型、运算符
- 流程控制：if / for / while
- 函数与模块
- 文件读写

```python
# 第一个程序
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("云舒卷"))
```

## 第二阶段：进阶特性（3 周）

- 列表推导式、生成器
- 装饰器与闭包
- 面向对象：类、继承、多态
- 异常处理

## 第三阶段：实用方向（4 周）

按兴趣三选一：

1. **Web 开发**：FastAPI / Django

3. **AI 应用**：调用大模型 API 做应用（参考 [[RAG 技术入门]]）

## 常见坑

- 可变默认参数：`def f(x=[])` 是反模式
- 全局变量修改需 `global`
- `is` 与 `==` 的区别
