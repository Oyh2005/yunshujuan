# 产品需求文档：智能笔记助手

## 背景

用户反馈"笔记写了从不回看"，希望有一个能自动整理、定期提醒复习的笔记工具。

## 目标用户

- 学生：课堂笔记 + 考前复习
- 知识工作者：阅读笔记 + 写作素材
- 终身学习者：任何需要持续积累的人

## 核心需求

1. **笔记管理**：新建、编辑、分类、搜索
2. **智能回顾**：按遗忘曲线提醒复习
3. **AI 问答**：基于个人笔记回答问题
4. **双链笔记**：笔记之间建立关联（参考 [[技术选型讨论]]）

## 非功能需求

- 数据安全：用户数据隔离
- 响应速度：页面加载 < 1 秒
- 移动端适配

## 里程碑

- M1：笔记 CRUD + 搜索
- M2：AI 问答接入
- M3：回顾系统
- M4：双链与图谱

## 风险

- AI 服务成本不可控 → 需要限流与缓存
- 用户隐私顾虑 → 默认私有

详见技术侧的 [[技术选型讨论]]。
