# 向量数据库

## 什么是向量数据库

向量数据库专门用于存储和检索高维向量数据。文本、图片、音频都可以被模型转换成向量，向量之间的距离代表语义相似度。

## 常见产品

| 产品 | 特点 | 适用场景 |
| --- | --- | --- |
| ChromaDB | 轻量、嵌入式 | 个人项目、原型 |
| Qdrant | Rust 编写、性能好 | 生产环境 |
| Milvus | 分布式、大规模 | 企业级 |
| pgvector | PostgreSQL 插件 | 已有 PG 的场景 |

## 核心概念

- **集合（Collection）**：类似数据库中的表
- **向量维度**：模型决定，如 768 维、1024 维
- **相似度算法**：余弦相似度、欧式距离、内积

## 在 RAG 中的角色

在 [[RAG 技术入门]] 的检索环节，向量数据库负责"找相似"。检索质量取决于：

1. 切片的粒度
2. 向量模型的质量
3. 检索算法的选择
