# 大语言模型基础

## 大语言模型是什么

大语言模型（LLM）是通过海量文本训练出来的神经网络模型，能够理解自然语言并生成连贯的回复。它的核心能力是"预测下一个词"，但在海量数据和足够参数量下，涌现出了理解、推理、翻译等能力。

## 主要能力

- 文本生成与续写
- 摘要与改写
- 代码编写
- 多轮对话
- 少量示例学习（Few-shot）

## 局限与挑战

1. **知识截止**：训练数据有时间上限
2. **幻觉**：可能一本正经地编造答案
3. **上下文长度**：一次能处理的文本有限
4. **成本**：大模型调用费用不低

## 嵌入（Embedding）

嵌入是把文本映射为向量的过程，是 [[向量数据库]] 的输入来源。同一个模型生成的向量，语义相近的文本距离更近。

## 与 RAG 的关系

[[RAG 技术入门]] 就是用检索来弥补上面说的"知识截止"和"幻觉"问题——让模型基于真实资料回答，而不是凭空编造。

## 实践建议

学习路线建议：先理解本文基础概念，再读 [[RAG 技术入门]] 了解应用，最后用 [[向量数据库]] 动手实践。
