# RAG 技术入门

## 什么是 RAG

RAG（检索增强生成）是一种让大模型"先查资料、再回答问题"的技术方案。核心思路是：在模型生成回答之前，先从知识库中检索出与问题相关的内容，作为参考材料一起交给模型。

## 为什么需要 RAG

[[大语言模型基础]] 中提到，大语言模型的知识有截止日期，且无法知道私有数据。RAG 正好解决这两个问题：

1. 知识可以随时更新（往库里加文档即可）
2. 私有数据不出库（检索发生在本地）

## 关键组件

- 文档切片：把长文档切成小块
- 向量化：把文本变成数字向量
- 检索：找出与问题最相似的片段
- 生成：把检索结果交给模型组织答案

## 与向量数据库的关系

检索环节依赖 [[向量数据库]] 来存储和查找向量。向量数据库的选择直接影响检索速度和准确率。

## 小结

RAG 是当前落地 AI 应用最实用的技术之一，入门门槛低，效果立竿见影。推荐继续阅读 [[向量数据库]] 和 [[大语言模型基础]]。
