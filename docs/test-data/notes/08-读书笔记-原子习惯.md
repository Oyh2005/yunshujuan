# 读书笔记：原子习惯

## 一句话概括

不要追求惊天动地的改变，而是每天进步 1%，让好习惯自动运转。

## 核心观点

### 1. 习惯的四个环节

提示 → 渴望 → 反应 → 奖励

要让习惯容易坚持，就要让"提示显而易见、渴望有吸引力、反应轻而易举、奖励令人满足"。

### 2. 两分钟法则

把任何新习惯压缩到两分钟内可以完成：

- "每晚读书" → "睡前读一页"
- "每天锻炼" → "换上运动服"
- "开始写作" → "写一句话"

### 3. 身份认同

不要定目标"我要读完 12 本书"，而是认定"我是一个读书的人"。习惯是身份的体现。

## 金句摘录

> 你并没有上升到你的目标水平，而是下降到你的系统水平。

> 每一个习惯都是投票给你想成为的那种人。
