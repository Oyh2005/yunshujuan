# 云舒卷附属页面 UI 优化计划

> 基线：2026-08-29 当前工作区源码；历史 Skill 和效果图只作视觉参考，不覆盖现行实现。

## 修改原则

- 每个阶段开始前重新读取目标文件和 `git diff`，以工作区最新代码为准。
- 保留用户已有未提交修改，优先增加局部类名和独立样式，不整文件替换。
- 不改变现有接口、状态管理、权限和业务能力。
- 工作台侧栏固定为展开 `206px`、折叠 `68px`、手机 `56px`，非首页保留全局页宠。
- 每阶段完成后检查目标文件差异，并验证桌面、移动端、深色与关键交互。
