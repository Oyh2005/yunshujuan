## ① 视觉基础包（`ec77b19`，纯前端）
- **气泡旁头像**：对方消息左侧、自己消息右侧显示头像（微信式左右分栏）
- **时间分组**：今天/昨天/日期分组标题 + 相邻 >5 分钟消息单独显示时间
- **乐观发送 + 状态**：发送中（转圈）→ 成功替换服务端消息 → 失败标记"未发送" + 点击重发（引用/图片消息重发保留类型与引用）
- 已读/未读状态保留（微信没有，我们更优）

## ② 输入增强（`b00a927`）
- **emoji 表情面板**：48 个常用表情，点击插入输入框（输入区 Smile 按钮 toggle）
- **图片消息**：输入区图片按钮 → `POST /social/chat/upload-image`（校验 png/jpg/gif/webp + ≤10MB，存 `backend/media/chat/{user_id}/`）→ 发 `message_type=image` 消息；气泡渲染图片 + **点击放大预览**（遮罩 Modal）；会话列表预览显示「[图片]」
- `private_messages` 新增 `message_type` 列（text/image，自动 ALTER 迁移）

## ③ 消息操作（`2ac46d2`）
- **复制**：气泡 hover 菜单 → 复制消息内容
- **引用回复**：hover 菜单 Quote → 输入区显示引用条（可取消）→ 发送带 `reply_to_id`；后端**冗余存引用摘要**（`reply_content`，防原消息撤回后丢失）；气泡内显示引用块
- **撤回**：仅本人 + **2 分钟内**（微信规则，后端严格校验）；撤回后显示"你/对方撤回了一条消息"；会话预览同步更新；**WS recall 事件**实时推送
- 气泡 hover 操作菜单（复制/引用/撤回，仅未撤回且非发送中显示）

## ④ 会话管理（`4807989`）
- **个人设置表** `chat_conversation_settings`（user_id + conversation_id UNIQUE，置顶/隐藏按个人视角，双方互不影响）
- **置顶**：会话列表 hover Pin 按钮；置顶会话排最前（后端排序）
- **删除会话**：hover Trash + ConfirmDialog → `hidden=true`（仅自己视角隐藏，对方不受影响）
- **会话搜索**：列表顶部搜索框（按好友名/最后消息内容过滤）
- 会话列表接口：排除隐藏 + 返回 `is_pinned` + 置顶排序

## ⑤ 实时状态（`144342d`）
- **在线状态**：WS 连接时广播 `online`（排除自己，探针抓到过自推 bug 并修复）、断开广播 `offline`（多标签页仅完全下线才广播）；新连接推送 `online_list` 全量；会话列表头像右下角**在线绿点**
- **正在输入**：输入时 3s 节流发 `typing` → 服务端转发给目标 → 对方聊天窗头部显示"正在输入…"（3s 后消失）
