# 图谱检索与本机嵌入连接修复

## 问题与验证

首页自动加载图谱，原接口对笔记批量调用语义检索，并且重复检索知识库。检索异常被捕获，因此接口返回 200，但日志持续出现 502。

使用不含用户数据的 `connection check` 测试本机 `localhost:11434` 的 `nomic-embed-text`：默认网络配置连接失败；禁用代理继承后返回 768 维向量。修复后通过实际 `EmbedModelFactory` 再次调用成功。没有更改模型、凭据、系统代理或重建向量数据。

## 修改

- 仅针对 localhost / loopback 嵌入服务，配置同步和异步直连；远程模型沿用原网络设置。
- `/note/graph` 默认 `include_semantic=false`，仅读取笔记和已有双链；首页显式使用该模式。
- 图谱页新增“加载语义关联”，由用户主动触发；加载失败保留图谱并显示提示，支持重试。
- 图谱语义查询只查笔记，不重复查询知识库；遇到服务失败停止本轮后续查询。
- 关联检索跳过空内容、没有其他笔记和当前用户的空知识库；笔记检索增加用户隔离过滤。
- 返回语义状态 `not_requested / complete / partial / unavailable`，不再把失败伪装成已完成。

- 浏览器独立模拟数据检查：11 passed，包含自动请求、手动加载、失败保留图谱、重试和响应式布局；没有修改真实用户数据。
- 前端生产构建通过；修改涉及的 TypeScript 文件 ESLint 检查通过。
