# 云舒卷 · 页宠功能企划书

> 创建日期：2026-08-26
> 状态：待审核
> 目标：为云舒卷（RAG 智能笔记助手）添加一个可互动、有陪伴感的页宠，提升产品温度和品牌辨识度。

---

## 1. 功能概述

页宠（Desktop Pet / 看板娘）是常驻在网页角落的虚拟角色，具备：

- **存在感**：常驻页面右下角，待机动画（呼吸、眨眼、摇尾巴）
- **可互动**：点击/戳一戳有反应，可拖拽移动，会说话（气泡）
- **有情绪**：根据应用事件做出反馈（保存笔记→庆祝、AI 思考→等待、长时间不用→睡觉）
- **可管理**：随时隐藏/召唤，位置记忆

**一句话定位**：一个懂你笔记习惯的"桌面小精灵"，让知识管理不再孤单。

## 4. 技术方案

### 4.1 渲染方案对比

| 方案 | 效果 | 体积 | 复杂度 | 素材成本 |
| --- | --- | --- | --- | --- |
| **A. 自绘 SVG 角色 + CSS/Framer Motion 动画（推荐）** | 简洁精致、风格统一 | <50KB | 低 | 自绘（无需外部资源） |
| B. Live2D 看板娘（Cubism SDK） | 最精致、动作丰富 | 模型 2~20MB | 高（SDK + 模型资源） | 需下载开源模型（网络依赖） |
| C. Emoji/CSS 组合宠物 | 可爱但质感一般 | <5KB | 极低 | 零成本 |

**推荐 A**：零外部依赖、离线可用、无版权风险、与现有设计系统（CSS 变量/主题）天然融合；动画用 CSS keyframes + Framer Motion（已安装）。**B 作为后续可选升级**（接口预留）。

### 4.2 技术要点

- **组件**：`components/pet/Pet.tsx`（角色）+ `PetBubble.tsx`（气泡）+ `usePetStore.ts`（Zustand 状态：显隐/位置/情绪）
- **状态机**：`idle → walk → drag → talk → celebrate → sleep → think`，事件驱动切换，带超时回退（如 celebrate 3s 后回 idle）
- **渲染**：SVG 内嵌组件 + CSS 类切换动画（眨眼/呼吸/摇动用 keyframes；拖拽/移动用 Framer Motion）
- **挂载**：MainLayout 登录后渲染（与氛围背景同层），`pointer-events-none` 包裹、子元素单独开启
- **持久化**：`localStorage`（位置坐标、显隐开关、好感度/成就）
- **无障碍/性能**：`prefers-reduced-motion` 时静态展示；空闲降频（呼吸动画用 transform 不触发重排）；隐藏时组件卸载零开销

## 5. 交互设计

### 5.1 状态机

```
                    ┌──────────┐
   点击/抚摸 ──────▶ │  talk    │
                    └────┬─────┘
      idle ◀──(3s超时)────┤
      ▲                   │ 保存笔记/完成回顾
      │                   ▼
  (30s无操作)          ┌──────────┐
      │                │celebrate │
      └──── sleep ◀────┴────┬─────┘
          (打盹 zzz)         │
                     (拖拽)  ▼
                     ┌──────────┐
                     │  drag    │
                     └──────────┘
```

- **idle**：呼吸 + 随机眨眼，偶尔（每 60~120s）冒一句随机台词
- **talk**：点击/抚摸时，气泡显示一句台词 + 高兴动画
- **celebrate**：保存笔记、完成每日回顾、上传文档成功时触发
- **sleep**：30 秒无操作后打盹（呼噜 zzz），点击唤醒
- **drag**：按住可拖拽，松手落在新位置（记忆）

### 5.2 气泡台词（示例）

| 场景 | 台词 |
| --- | --- |
| 随机问候 | "今天想记录点什么呀？(=^▽^=)" / "笔记写了要常回看哦~" |
| 保存笔记 | "记好啦！又进了一步！" |
| AI 回答完成 | "他好厉害，我都听入迷了~" |
| 完成回顾 | "复习打卡成功！记忆 +1！" |
| 上传文档 | "正在把知识塞进小仓库…" |
| 长时间闲置 | "zzz… 你终于来啦！" |
| 打招呼（首次） | "你好呀！我是小卷，以后请多指教~" |

### 5.3 管理与控制

- 宠物身上悬浮菜单（hover 显示）：隐藏宠物 / 切换语言问候 / 关于
- **设置页**新增"页宠"开关 + 形象预览（可切换形象，若多形象）
- 隐藏后可通过设置页或侧边栏快捷按钮重新召唤

## 7. 应用事件联动表（P1）

| 应用事件 | 宠物反应 | 触发点 |
| --- | --- | --- |
| 笔记保存成功 | celebrate + "记好啦！" | NoteEditor 保存回调 |
| AI 对话流式输出中 | think 状态（托腮等待） | AIChat SSE onThinking |
| AI 回答完成 | 鼓掌/开心 | SSE onDone |
| 每日回顾完成 | celebrate + 打卡台词 | DailyReview 提交成功 |
| 知识库上传中 | 搬运动画 + 进度气泡 | SSE 上传进度事件 |
| 长时间无操作 | sleep（zzz） | 全局定时器 |
| 每日首次打开 | 早安台词 | 应用挂载 |

> 联动通过轻量事件总线实现：`usePetStore` 暴露 `trigger(eventName)`，各页面在成功回调里调用，**不侵入业务逻辑**。

## 9. 性能与兼容性

| 项 | 策略 |
| --- | --- |
| 动画开销 | 全部用 `transform`/`opacity`（GPU 合成），空闲静止时无动画 |
| 电量 | 待机动画频率低（呼吸 3s 周期）；隐藏时组件卸载 |
| 小屏/移动端 | <768px 默认隐藏（避免遮挡），可在设置中强制开启 |
| 浏览器 | Chrome/Edge/Firefox/Safari 现代版本；`prefers-reduced-motion` 静态化 |
| 与现有功能 | 零冲突：`pointer-events` 隔离、z-index 低于弹窗/对话框 |

## 12. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 动画影响操作（遮挡按钮） | 默认小尺寸（~80px）+ 右下角 + 可拖拽/隐藏；pointer-events 精确控制 |
| 用户觉得烦 | 设置页一键关闭；台词库克制不刷屏（间隔 ≥60s） |
| SVG 角色质感不足 | 提供 Live2D 升级路径（组件接口预留 `CharacterRenderer` 抽象） |
| 包体/性能 | SVG 方案 <50KB；动画全部 GPU 合成 |
